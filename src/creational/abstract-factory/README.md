# Abstract Factory

Implementação em TypeScript do padrão Abstract Factory.

Descrição rápida:

- O padrão Abstract Factory fornece uma interface para criar famílias de objetos relacionados ou dependentes sem especificar suas classes concretas.
- Este exemplo apresenta duas famílias de produtos (botões e checkboxes) e duas fábricas concretas (Windows e Mac).

Como executar:

```bash
# a partir da raiz do projeto
ts-node src/creational/abstract-factory/index.ts
```
